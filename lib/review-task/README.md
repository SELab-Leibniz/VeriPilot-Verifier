# Native task review adapter

OpenClaw owns authentication, its model catalog, agent/tool loop, session persistence, provider retries and context compaction. RC supplies a frozen evidence protocol through `runReviewTask({ nativeRun, ... })`; it does not implement a general agent loop or import a host dependency. The production factory injects this executor through the existing `runTask` seam for Stop single items, groups, file quality and shared M09/M12/M16 implementation reviews.

`registerTaskTools(api)` registers source_read, source_grep, source_find, source_ls, review_history and submit_review through the real plugin tool factory. Definitions exist only for the exact private reviewer session and expire on close/cancellation. The native run has an explicit allow-list. Business sessions do not receive these tools. Sandboxed tool factories fail closed rather than bypass filesystem policy.

The source tools navigate only captured paths. source_read returns at most 400 complete lines and 51200 UTF-8 bytes, with nextOffset. It splits returned original text into blocks of at most 6000 bytes because the installed host truncates individual observer blocks at 8000 characters. A single source line larger than one page is unavailable and cannot become a read proof. Only a successful sanitized host result matching all disclosed bytes promotes the pending citeId and range. Arguments, summaries, grep hits and historical observations grant no coverage. Complete basis reads, current-target citations, original byte offsets/hashes, M16 productionTrace and final currentness checks remain required.

The RC observation journal is independent of OpenClaw JSONL/SQLite transcripts. It archives acknowledged public tool output and public assistant text; review_history restores navigation and previously acknowledged cite metadata after host compaction. It cannot mint a new read receipt. Checkpoint v2 rejects prior executor checkpoints instead of reusing their receipts. Checkpoints are written at native compaction hooks and run close; reload verifies the source manifest, hashes, offsets and original receipt bytes. There is no dependency on a host-internal session manager.

`reviewPromptProfile(metricId, scope)` and `REVIEW_PROMPT_PROFILE_DIGEST` retain the existing metric instructions. The native task cache identity is versioned separately from the removed executor. The only independent runtime dependency here is typebox 1.3.27 for JSON schemas. Run `npm ci --prefix lib/review-task --ignore-scripts` for development. OpenClaw artifacts include the same exact schema dependency and lock; install them with `npm ci --ignore-scripts`. No Pi package is installed or imported by RC. Historical experimental snapshots are excluded from artifacts.

Node >=22.19 is required for the OpenClaw task path; the Node 18 CLI does not eagerly load it. `test/review-task-engine.test.mjs`, `test/openclaw-task-runtime.test.mjs` and the Stop suites use scripted native contracts. The real installed-host diagnostic is `scripts/diagnostics/stop-correction-ma-contract.mjs`; its loopback provider is not a real-model accuracy test.
