# HarmonyOS TodoList 需求

## 目标与范围

面向单设备个人用户，实现待办新增、完成和取消完成。本轮只使用本地存储，不实现账号、云同步、推送、真实后端或跨设备同步。

## 系统需求

- `REQ-TODO-001`：用户输入非空内容后可以新增待办；空白输入不创建记录。
- `REQ-TODO-002`：用户可以完成和取消完成已有待办。
- `REQ-TODO-003`：终止应用进程并重新启动后，待办内容和完成状态必须恢复。
- `REQ-TODO-004`：本地保存失败时保留当前内存状态，提示失败并允许重试。

## 事实、假设与待确认

- 事实：范围由 `prompt/user-request.md` 确认；`baseline_workflow.yaml` 是本轮 Prompt Contract。
- 假设：目标项目支持 ArkTS 本地持久化能力。
- 待确认：目标 API Level 和设备型号由执行阶段绑定，不在需求阶段猜测。
