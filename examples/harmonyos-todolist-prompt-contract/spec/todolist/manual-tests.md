# HarmonyOS TodoList 手工测试契约

## 测试环境

执行时绑定当前源码构建的新 HAP、目标设备、包名、Ability、应用数据目录和测试 revision。文档设计测试契约，不在本阶段宣称已经执行。

## 手工测试用例

- `MTC-TODO-001`：初始空列表，输入“购买牛奶”并确认，断言列表出现同名未完成待办。
- `MTC-TODO-002`：完成 `MTC-TODO-001` 的待办，断言完成态；再次操作，断言取消完成。
- `MTC-TODO-003`：新增并完成待办，终止进程，重新启动应用，断言内容与完成状态恢复；不得卸载或清数据。
- `MTC-TODO-004`：注入保存失败，断言当前内容仍可见、出现失败提示并可重试；恢复存储后重试成功。

每条执行记录必须关联对应 `REQ-TODO-*`、当前 revision 和证据路径。
