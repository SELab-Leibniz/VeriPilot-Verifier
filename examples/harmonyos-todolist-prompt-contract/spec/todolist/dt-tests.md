# HarmonyOS TodoList DT 测试契约

## DT 范围

隔离验证 `TodoStore` 的状态转换、序列化、重建恢复、损坏快照和保存失败恢复；真实应用冷启动旅程仍由手工测试覆盖。

## DT 用例

- `DT-TODO-001`：空状态新增待办，断言生成稳定 ID、正确文本和未完成状态。
- `DT-TODO-002`：切换完成态两次，断言 `false → true → false`。
- `DT-TODO-003`：写入快照、重建数据服务、读取并断言 ID、文本和完成状态不变，随后清理测试数据。
- `DT-TODO-004`：存储写入失败，断言返回明确失败、内存状态仍可读；恢复后重试并断言持久化成功。

每条 DT 都绑定对应 `REQ-TODO-*`，并明确前置、输入、步骤、断言和清理。
