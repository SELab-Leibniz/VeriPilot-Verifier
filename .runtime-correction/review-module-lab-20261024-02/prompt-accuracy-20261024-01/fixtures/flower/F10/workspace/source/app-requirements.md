## 一、产品概述

### 1.1 产品定位

一款面向C端用户的**花店电商App**，支持商品浏览、下单购买、配送提醒、社交分享等核心电商能力，同时具备语音搜索、扫码购、定位门店等差异化功能。

### 1.2 目标用户

- 18-45岁有购花需求的城市用户
- 习惯移动端购物的消费者
- 对便捷购物体验有追求的用户（语音、扫码、定位）

### 1.3 核心价值主张

**"选花更便捷，送花更贴心"**

- 多种找花方式：列表/搜索/扫码/语音/定位
- 购买体验流畅：快速下单 + 配送提醒
- 社交分享：分享给好友/添加到通讯录

## 二、用户角色与权限

### 2.1 用户角色

| 角色 | 描述 | 权限范围 |
|------|------|---------|
| 游客 | 未登录用户 | 浏览商品、定位门店、扫码、搜索 |
| 注册用户 | 华为账号登录 | 以上全部 + 下单、收藏、通知、支付 |

### 2.2 隐私权限说明

首次使用特定功能时，应用会请求以下权限：

| 权限 | 触发场景 | 用途说明 |
|------|---------|---------|
| 位置 | 点击定位按钮 | 查找附近门店 |
| 通知 | 点击购买按钮 | 发送订单确认通知 |
| 日历 | 点击配送日历 | 添加配送提醒到日历 |
| 麦克风 | 点击语音搜索 | 语音输入商品名称 |

## 三、用户旅程与功能需求

### 3.1 首页浏览

**用户故事**: 作为游客/用户，我想在首页浏览商品列表，快速找到我喜欢的花束。

#### 3.1.1 商品列表

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 商品展示 | 展示商品卡片：图片、名称、价格 | 图片加载时显示占位图 |
| 手动刷新 | 下拉刷新获取最新商品 | 刷新时有loading反馈，网络失败时降级显示本地缓存 |
| 浏览历史 | 底部区域展示最近浏览过的商品 | 记录最近10条，关闭App后仍保留 |
| 附近门店 | 点击定位按钮获取位置，展示附近门店列表 | 需用户授权位置权限 |

#### 3.1.2 找花方式

| 方式 | 入口 | 描述 |
|------|------|------|
| 扫码购 | 首页扫一扫图标 | 扫描花束/包装上的二维码，自动跳转到对应商品详情页 |
| 语音搜索 | 首页麦克风按钮 | 点击后说话，说出商品名称（如"红玫瑰"），自动搜索 |
| 附近门店地图 | 定位按钮旁的地图图标 | 跳转到地图页，展示附近花店位置 |

### 3.2 商品详情

**用户故事**: 作为用户，我想在商品详情页了解商品信息，并完成购买。

#### 3.2.1 商品信息展示

| 需求 | 描述 | 技术说明 |
|------|------|---------|
| 大图展示 | 商品主图，支持查看大图 | 图片加载失败显示默认占位图 |
| 价格展示 | 显示售价 | 价格数字支持屏幕朗读（无障碍） |
| 商品描述 | 商品名称、花语、规格 | 文本信息 |

#### 3.2.2 收藏功能

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 收藏/取消 | 点击收藏按钮切换状态 | 状态实时更新，关闭App后重新打开仍保留 |
| 收藏图标 | 已收藏显示实心♥，未收藏显示空心♡ | 收藏按钮支持屏幕朗读 |

#### 3.2.3 优惠与服务

商品详情页底部提供"优惠与服务"卡片，包含以下功能入口：

| 功能 | 描述 |
|------|------|
| 配送日历提醒 | 添加配送日期到系统日历 |
| 分享给好友 | 分享商品链接/图片到微信/QQ等 |
| 添加收货人 | 将收货人信息添加到通讯录 |
| 智能花瓶 | 查看蓝牙智能花瓶状态 |
| 晒图评价 | 选择图片晒图评价 |

#### 3.2.4 晒图评价

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 选择图片 | 拍照或从相册选择 | 系统弹出图片选择器，无需申请存储权限 |
| 预览已选图片 | 显示已选择的图片缩略图 | 支持删除已选图片 |

### 3.3 购买流程

**用户故事**: 作为用户，我想快速完成下单，并收到订单确认通知。

#### 3.3.1 立即购买

| 步骤 | 描述 |
|------|------|
| 1. 点击购买 | 触发订单确认通知 |
| 2. 发送通知 | 发送订单确认消息到系统通知栏 |
| 3. 跳转支付 | 跳转到支付页面（功能预留） |

#### 3.3.2 订单通知

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 发送通知 | 购买成功后发送系统通知 | 需用户授权通知权限 |
| 通知内容 | 包含商品名称、订单号 | 通知ID由系统管理 |
| 拒绝处理 | 用户拒绝通知权限时，提示用户可在设置中开启 | - |

### 3.4 支付安全

**用户故事**: 作为用户，我想安全地管理我的支付密码，防止泄露。

#### 3.4.1 支付密码设置

| 需求 | 描述 | 技术说明 |
|------|------|---------|
| 设置密码 | 用户输入6位支付密码 | 密码本地AES加密存储 |
| 验证密码 | 下单时验证支付密码 | 使用存储时同一密钥解密比对 |
| 清除密码 | 支持清除已设置的密码 | 同时清除加密数据和密钥 |

#### 3.4.2 生物认证（功能预留）

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 身份认证 | 支持指纹/PIN/人脸验证 | 真机上测试，模拟器不支持 |
| 认证失败 | 显示友好错误提示 | 不直接显示错误码 |

### 3.5 账号系统

**用户故事**: 作为用户，我想登录华为账号，以便使用完整的电商功能。

#### 3.5.1 华为登录

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 登录入口 | "我的"页面提供华为账号登录按钮 | 未登录时显示登录按钮 |
| 登录方式 | 弹出华为账号登录授权页面 | 支持已登录华为账号静默授权 |
| 登录状态 | 登录后显示用户信息 | 显示头像、昵称 |

### 3.6 门店地图

**用户故事**: 作为用户，我想查看附近的花店位置，方便到店自取或查看实体店。

| 需求 | 描述 | 技术说明 |
|------|------|---------|
| 地图展示 | 展示门店位置标注 | 使用华为地图服务 |
| 当前位置 | 显示用户当前位置 | 需用户授权位置权限 |
| 点击标注 | 点击门店标记显示门店信息 | 显示名称、地址、电话 |

### 3.7 配送日历

**用户故事**: 作为用户，我想将配送日期添加到系统日历，避免错过重要日期。

| 需求 | 描述 | 验收标准 |
|------|------|---------|
| 选择日期 | 选择配送日期 | 从日历组件选择 |
| 添加到日历 | 创建配送提醒日程 | 需用户授权日历读写权限 |
| 事件内容 | 日程标题为"花束配送" | 包含商品名称、收件人信息 |

## 五、数据结构设计

### 5.1 客户端本地存储

| 数据 | 存储方式 | 说明 |
|------|---------|------|
| 收藏列表 | Preferences (arkdata) | key: "favorites"，存储商品ID数组 |
| 浏览历史 | Preferences (arkdata) | key: "browse_history"，存储最近10条 |
| 支付密码 | Asset (asset-store-kit) | AES加密后存储，保障安全 |
| AES密钥 | Asset (asset-store-kit) | 与密码一起存储，解密时使用 |

### 5.2 网络接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/commodities | GET | 获取商品列表 |
| /api/commodities/{id} | GET | 获取商品详情 |

**降级策略**: 网络请求失败时，自动降级到本地mock数据，保障应用可用性。

## 八、非功能性需求

### 8.1 性能要求

| 指标 | 要求 |
|------|------|
| 首页加载 | 首屏显示 < 2秒 |
| 页面跳转 | 路由切换 < 500ms |
| 图片加载 | 占位图先行，渐进加载 |

### 8.2 无障碍要求

| 元素 | 无障碍属性 | 说明 |
|------|-----------|------|
| 价格 | accessibilityText + accessibilityLevel | 屏幕朗读能正确播报 |
| 收藏按钮 | accessibilityText + accessibilityLevel | 朗读"已收藏"或"未收藏" |
| 商品图片 | alt文本 | 描述商品名称 |

### 8.3 兼容性

| 项目 | 要求 |
|------|------|
| 最低系统版本 | HarmonyOS 4.0 |
| 目标设备 | 手机、平板 |
| 模拟器支持 | 部分功能（生物认证、蓝牙BLE不可用） |
