# Document correction

Each round has a new request and authority. Previous conversation and private notes are navigation hints, never proof or user instructions. Re-read current target documents, applicable criteria and ready workflow sources. Review every available target and enabled edge; unavailable prerequisites remain deferred. Keep source documents read-only and edit proposals within this round's editable list.

When `rc_document` is available, start with `open`: one call returns the manifest, hash-checked notes and bounded current document pages. Use `read` for every remaining `nextLine`/`requiresRead` and `search` for exact terms within one declared document. Both actions require its exact manifest `path`. Use `recall` after compression. `requiresHostRead` means a line exceeds the page budget. Use the host's permitted read/search tools for further original evidence, including the request's `originalRequirements` message files and requirement sources. Read additional project files when a current criterion or a claim in the artifact depends on them. Defer discovery of downstream artifacts until they are supplied or the current artifact relies on them as existing evidence. A partial page or search result does not establish whole-document compliance.

When the current request includes original user messages, start from those sources for intent. Consult the frozen transcript when an applicable criterion or a claim in the artifact depends on what the agent or a tool actually did.

`originalRequirementCoverage` describes coverage by this round's declared current artifact targets. It is not a report of whole-project implementation or executed checks. A `COVERED` row needs at least one current target range disclosed by `rc_document.open` or `read`. Other source files can supply context, but cannot serve as coverage targets unless they are declared current artifacts. For an optional row, omit an obligation only when the original does not require this artifact scope to represent it; otherwise retain `UNVERIFIED` if coverage cannot be established. Never invent a target range to repair a response. Every obligation listed by `required_proposal` still needs its own row and the required coverage; none may be omitted to escape validation. Judge implementation and execution claims separately using their applicable current evidence.

Use `remember` only for useful decisions or pending checks, with a short key and paths already read this round. It writes private project notes, never business files. Notes with changed files, policy or authority are stale. After context compression, reload the current request, manifest and notes; do not replay old findings. Keep exceptions, authority and unresolved dependencies intact.

Return the current round's required JSON. Findings need current original evidence; edits need exact current line text. The program rechecks file hashes and patch expectations before accepting results. Report uncertainty when the evidence is incomplete. Do not copy the repository, start another agent, run commands, apply edits, or send phase messages to the host conversation. The program owns session lifecycle and the compact progress indicator.

Finding locations use physical 1-based CURRENT source lines, as numbered by rc_document; never count sentences or visual line wrapping. A declared `path:line`/`path#Lstart-Lend` followed by a verbatim quotation must contain that quotation at exactly that current location. Keep finding.line consistent with quoted evidence in the target document. Paraphrases, absence findings and document-level reasoning need not invent exact quotations or a numeric line. If validation rejects a location, re-read and correct the assessment; the program does not move your finding or change its diagnosis for you.

Distinguish document-content obligations from instructions governing the author's actions. Using or adopting a source as authoritative does not require an authority/adoption statement inside the artifact. Author workflow, review orchestration and execution-scope controls do not become required document paragraphs or disclaimers. Require such a statement only when the original task explicitly requests that output text or section. Preserve explicit documentation requirements; do not dismiss them merely because they discuss sources or authority. Resolve a requirement's proof subject, whether a baseline claim or an original user message, against its original source before treating an author action as missing artifact content.

For an explicitly configured copy contract, DOCUMENT-COPY-MISMATCH diagnostics compare current source and target characters, including literal-block indentation/spacing and EOF newlines. They are independent of semantic findings and cannot be cleared by a model PASS. Preserve the source's original heading levels and formatting rather than inventing style repairs. The permission to vary line-end padding outside literal blocks does not permit dropping newline characters or changing whitespace inside literal blocks.
