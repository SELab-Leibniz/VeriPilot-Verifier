# OpenClaw 受控执行与防递归

目标 OpenClaw 2026.7.1-2；插件 1.9.1-openclaw.3。实际验证范围以[验收记录](openclaw-acceptance.md)为准。

## 身份与控制权

runtime-corrector-supervised 注册为原生 agent harness，串行等待工作会话后调用原核心 Stop。工作会话固定使用 openclaw 运行时；其完成 Hook 只收集候选，不再评审或请求宿主重试。

| 身份 | 保留能力 | 拒绝的行为 |
| --- | --- | --- |
| 父任务控制器 | 记录真实要求，消费原决定，安排修正与交付 | 重入、重复派发 |
| 工作会话及修正轮次 | 原模型、工具检查、实际修改、正常复验 | 创建子控制器、将自动反馈当用户要求 |
| 只读评审 | 独立原生会话、冻结基线、结构化判断 | 修改成果、创建评审或控制器、递归追问自己 |

身份由运行时注册、私有会话绑定及共享 AsyncLocalStorage 判定，不依赖提示词标记。评审异步身份在模块重载和迟到回调中保留；只跳过评审自身 Hook，正常修正后的复验继续生效。已关闭或已完成轮次的绑定保留墓碑，旧 runId 不能更新新轮次。

工作身份在派发前写入 `.runtime-correction/openclaw/workers/`，关联父会话和控制器代次。进程重启后的旧工作会话仍不能创建控制器或触发新的纠偏任务，不依赖进程内绑定幸存。

## 需求、预算和收据

工作会话与父会话在原核心中映射到同一逻辑任务。纠偏指令使用 internal_system 来源；原需求版本、来源编号和偏差归因继续使用核心账本。真实补充必须有原生 user-turn recorder 并通过支持写入确认的排队接口。评审中收到补充要求会取消旧评审，再针对新要求执行。

控制器持有进程感知的父会话锁与已知任务锁。EXECUTING、ASSESSING 均在派发前持久化，结果进入 EXECUTED、ASSESSED 后才能消费。状态文件先 fsync 临时文件再原子重命名，最终结果有按父 runId 去重的收据。重复事件复用收据，旧代次写入被拒绝。重启发现未确认的执行、验收或交付记录时返回 UNVERIFIED，不重放可能产生副作用的操作。

控制器没有额外无限重试机制：原核心要求 block 才安排纠正，要求停止则停止。基础设施 UNVERIFIED 只重试评审，不再执行工作会话。冻结 population 漏评、重复或越界同样进入原独立基础设施重试，避免检查器错误消耗实际纠偏预算。

## 取消、证据与交付

父 abortSignal、replyOperation、活动句柄、reset/dispose 与配置关闭统一取消工作和评审。每次续跑、最终写入前核对取消、代次、待接收要求与证据。工作会话 sessionKey 与 sandboxSessionKey 都使用私有身份，因为目标宿主把后者同时用于消息事件。父会话的有效沙箱模式和工具策略由公开 SDK 解析并复制到每次运行配置，全局配置不变。

控制器登记自身工作轮次和评审的原生 runId，通过公开 diagnostic-runtime SDK，将这些运行的真实模型、工具和流式进展转为父运行的 run.progress。宿主因此能识别仍在工作的父任务。其他任务、已结束轮次、取消后的迟到回调不会续期；父进展也不会再次被当成内部进展转发。没有定时心跳，真正无进展时仍由宿主原策略处理。

只有 TASK_COMPLETE、报告 PASS、原任务 COMPLETED/verification PASS、证据未变且未取消，才交付候选结果。逐文件哈希覆盖工作会话显式读写和评审读取；评审读到不稳定文件，即使随后恢复字节也不通过。无关文件修改不会使另一个并行任务失效。

父历史追加真实用户消息、配对工具证据和最终结果，候选与自动提示保留在私有 worker/round 记录。最终写入使用父 runId 作为宿主幂等键，避免 Gateway 重复追加。进度使用完整文本快照，由最终结果替换。结束事件遵循宿主 finishing/end 约定，避免终端出现幽灵运行。

只有父运行继承宿主的延迟终止设置，私有工作会话明确关闭延迟终止，完成自身生命周期；不会让已完成的子会话滞留在 finishing 状态。

## 固定版本兼容层

lib/openclaw/compat-2026.7.1-2.mjs 只读导入已安装目标宿主。公开 SDK 提供运行句柄、转录写入、事件和沙箱策略；私有桥集中封装确认排队、原生执行器选择及用户转录记录器。加载检查版本、导出与确认能力，专项测试在真实安装上验证契约，不修改或替换宿主文件。

自动测试覆盖嵌套评审、子控制器、重复通知、跨进程互斥、重启歧义、迟到代次、两会话并行、真实补充、预算耗尽、基础设施重试、等待用户、取消与评审竞争、关闭与重置、证据变化。模型与界面测试另行记录，不以单元或契约测试替代。
