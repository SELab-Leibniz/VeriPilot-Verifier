# Stop 调用链修复（2026-10-24）

分支：`codex/stop-call-chain-fixes`；起点：`183c20f`。完整 Stop、厨房端到端长跑保持暂停；原项目、原会话和原 Gateway 不作修改。本轮先修程序边界，不通过扩大预算、删除验收条件或反复抽取期望结果取得通过。

## 本轮范围

沿“准备材料 → 分派单项 → agent 取证 → 验证结果 → 保存 → 汇总 → 决定结束”统一修复。模型仍负责语义判断；程序负责身份、取证出处、读取范围、当前性、保存、计数和结束政策。没有新增生产评审 agent 或总评工作流。

### 取证与结果接受

新增共享结果验证器，SDK、OpenClaw native、可提供读取事件的 Claude CLI 使用同一证据门槛。源引用上携带程序产生的 `readProof`：版本、证据角色、真实披露、完整必读依据。模型输出仍是短判断、原因与引用；不能自己声明读取证明。

- SDK 复用已验证的完整 basis、citeId、范围和 SHA；只根据实际引擎结果生成证明。
- native 通过真实 read 调用及其返回内容登记区间；只发出读取参数、引用文件存在、助手陈述、失败或无法核验的返回格式都不足以证明已读。
- Claude CLI 复用原生 `stream-json` 工具事件，配对 Read/tool_result，并核对会话身份、顺序及原文字节；格式修复与后续调用沿用同一角色的读取记录。普通 GT、分类和非验收 JSON 接口保持原行为。
- 四种排除状态也必须有完整依据和适当证据，不能凭空移出分母。TASK_COMPLETE 时，HARD 必执行项不能借 NOT_YET_EXECUTED 豁免。
- 模型声称 P/D/排除，但程序无法核验读取证明时，这是检查器错误：该项未完成，保留原分母和有效兄弟，不扣业务纠偏次数。模型自己返回的合法 U 仍与检查器错误区分。

读取证明不机械保证语义正确。它确保模型确实接触了合法类型的原始材料；“这些材料能否支持结论”仍需要语义评审。

### 汇总、保存与反馈

文件质量 D/U 不伪造指标、不把 SOFT 升成 HARD，也不因此消耗业务纠偏次数；整体保留 UNVERIFIED / COMPLETED_WITH_ISSUES，并通过独立 FILE_QUALITY 条目给出机制、影响和证据位置。完整实验认证不能再忽略文件质量。

未知文件质量范围的空数组也不能自证完成：回退任务没有确定目标又没有任何文件判断时，记录 FILE_QUALITY_SCOPE_UNRESOLVED 检查器未完成，不虚构文件名、指标或已经验过的质量结论。只有程序明确不请求补充质量任务，才能跳过该职责。

反馈沿用每项768字节、总包8192字节和已有分页索引。完整长说明保存在独立详情中。native 收据保留有界未验证反馈；结束等待时可展示，并在下一次正常宿主 prompt 中提供明确标为历史的诊断，不自动启动新的业务轮次，不写成真实用户指令。

收集最终因期限到达而失败时，只向上层保留已保存数量和 progress 路径，不把过期 PASS 重新发布。源码变化、任务替换和取消继续使旧整体结论失效。checker 错误优先于业务 D 的状态计数，已证实的偏差仍可作为部分反馈保留。

### 准备与重复读取

- 先确定 Stop 范围；中间态、等待用户和外部阻塞不扫描交付候选。
- 候选扫描和读取继承原 Stop/父期限及取消；不扩大窗口。既有扫描 helper 仅增加可选活动检查，默认调用保持兼容。
- 纯过程证明不先复制无关业务树；显式必要源文件保留。运行验证仍可读取 verifier、实现及原始调用/结果，未删除原条件。
- 单轮收集缓存内容指纹：中间检查仍观察文件身份、大小及纳秒时间等变化；发布前对每个不同依赖强制重新计算完整内容 SHA。元数据只是优化线索，不是最终通过依据。
- 16项/16候选的无模型实验中，候选内容读取由544次降至32次。4项、8项分别为8次、16次。这里证明的是内容字节重读减少，不声称所有元数据检查已变成线性复杂度。
- 未引用但由程序观察到的公开读取依赖也参与发布检查，即使该传输没有缓存身份。缓存的128依赖容量限制不会拒绝较大的有效当前审查。

## 保持的边界

- 原有时间、token、读取和输出上限保持不变。
- 整份必要公共依据仍可能很大；不能靠删约束保证通过，超限时仍需有界失败和保留索引。
- 纯过程项没有可变业务文件依赖时，原 PASS 缓存仍保守不复用；没有添加无关文件充当假依赖。
- 没有可核验工具事件的 CLI 传输不能宣称已完成受保护的评审。CodeAgent 等无现成读取事件接口的路径明确降级，不构造不存在的接口。
- CLI 参数已用给定 Claude 可执行文件的 `--help` 核验。工具事件接线由真实假 CLI 进程和离线帧验证；不等于真实 Claude 模型或完整宿主已实测。
- 旧花店 F08 语义漏检、复杂案例和完整 Stop 的历史失败继续保留。本轮机制测试不构成准确率或完整 Stop 通过证明。
