# RC 控制台可观测性优化

目标：用户能在一个会话中判断插件是否触发、检查了什么、结果是否可靠、反馈是否进入宿主，以及下一步需要关注哪里。

## 现状与方案

当前页面围绕调度阶段和后续待办，只有最新基线版本和审查范围。运行证据分布在任务 journal、ground-truth、评估及宿主反馈回执中，不能把“触发成功”“审查通过”“反馈送达”合并成一种成功。

采用服务端只读投影 + 原有页面渐进增强，不增加前端框架、不修改 MatrixAssistant 或其 OpenClaw。新增响应快照记录实际 hook ID、会话、轮次、当时基线、检查类型和返回的反馈；已有产物与 Stop journal 保留原始语义。历史无法关联的字段显示未知，不从时间接近推断因果关系。接口沿用原有认证、只读权限与精确会话身份校验。

页面顺序：运行概览；当前基线（版本、待对齐、冻结、需求内容）与指标；响应记录（默认倒序、折叠、全文搜索、类型/需关注筛选、时间范围、分页）；原有待办与审查范围。

每条记录展示时间、轮次/hook ID、类型、结果、基线版本、指标明细、看护对象、反馈内容和送达依据。反馈区分未生成、已返回给宿主接口、已确认写入工具结果、宿主已接收续作、模型已观察、观察模式抑制、未知。未验证、技术失败、未启用、不适用保留原始原因。

## 实施顺序

1. 建立可复现临时任务样本，覆盖当前落盘格式及旧记录；验证关联规则。
2. 实现只读投影及认证 RPC：过滤后分页，旧记录可见，损坏证据显式提示。
3. 增加轻量响应快照，记录真实轮次和返回反馈，失败不能中断纠偏业务。
4. 优化控制台信息层级与检索，保留草稿、刷新、会话隔离和待办功能。
5. 用数据集实验、浏览器交互和相关回归测试验证，记录结果。

## 验收场景

- 正常触发无反馈：不能暗示已纠偏或完整验收通过。
- 产物出现偏差且有工具结果反馈：对象、反馈正文和送达依据可查。
- skill 看护：能辨认 skill 名称、状态、轮次和反馈。
- 新需求尚未对齐：基线 pending 清晰；旧版本 PASS 不计入当前通过。
- Stop 部分完成、检查器失败或指标未启用：各指标过/没过/未验证及原因正确。
- 反馈仅生成或 hook 返回但无回执：不能显示模型已收到。
- 多页记录：搜索涵盖全部数据，筛选后再分页，清除条件可恢复遍历。
- 会话快速切换/异步刷新：旧响应不得覆盖新会话，展开状态和编辑草稿保留。

性能实验使用至少 2,000 条时间线记录，检查全文搜索、筛选后分页以及响应大小；浏览器验证真实页面的折叠、检索、翻页和窄屏布局。实验只证明这些场景，不替代真实宿主端到端验收。

## 已实施及实验结果（2026-10-28）

采用上述方案。真实页面连接隔离实验 Gateway，调用生产 RPC、调度器与磁盘证据投影；宿主传输由测试替身承接，不联系真实模型。可重运行 `node scripts/console-experiment.mjs`；环境需有 Playwright 和 Edge，可用 `RC_PLAYWRIGHT_MODULE` 指向已安装的 Playwright 入口，`RC_BROWSER_CHANNEL` 切换浏览器。产物写入本 worktree 的 `.runtime-correction/console-experiment/`，含桌面/窄屏截图及 `results.json`。

- 数据验证：2,000 条响应中跨页全文搜索、筛选后分页、正反排序、时间边界均正确。一次本机查询约 16–20 ms，返回 25 条记录及概览约 14.8 KB；这是样本查询观察，不是服务时延保证。
- 浏览器验证：默认折叠与指标表、反馈正文搜索、文本安全呈现、类型/需关注筛选与清除、分页/排序、自动刷新保留展开和草稿、390px 窄屏无横向溢出、会话切换拒绝迟到响应、单条记录链接均通过。浏览器实验脚本共有 7 个检查项。
- 状态正确性：基线待对齐、证据被修改、基线正文不匹配时，历史 PASS 不作为当前通过；指标 MEASURED 按对象结论还原；缺失评估按未验证展示；旧日志缺少轮次和回执不会补造。
- 回归：完整 144 文件首轮有 143 文件通过，1 个宿主时序用例在并发负载下没有在两秒内看到派发，随后造成该文件 90 秒超时。单独重跑该文件 28/28 通过。最终相关回归 88/88 通过（含运行时、OpenClaw、三宿主插件打包、观察模式、新投影和认证接口）。保留首轮失败信息，未改宽原测试的等待条件。

## 使用与证据边界

轮次 ID 对应 RC 的 `turns.total` 助手轮次计数，Hook/工具调用 ID 另行展示。新版本启用后才有完整响应快照；旧记录只展示实际留存的证据。Skill watcher 的最新状态是快照，来源会明确标记，不冒充过去每次检查。

反馈“已生成”仅表示纠偏核心已产出并返回给适配层；工具结果回执、宿主接受续作和模型观察分别显示，不互相代替。指标表给出该次或当前基线的逐项结果，指标通过不自动等于整个任务通过。

单个证据文件超过 16 MiB 时当前投影会警示且跳过该文件，损坏的完整 JSONL 行会警示并跳过；活动写入中的不完整尾行暂不计入。需要更大规模长期留存时应在后续增加持久化索引或归档。此版本未完成真实 MA 浏览器认证及真实模型端到端验收，实验没有改动 MatrixAssistant 或其内置 OpenClaw。
