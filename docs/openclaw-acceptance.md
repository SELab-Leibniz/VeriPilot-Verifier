## 失败路径与限制

- 实际遇到过模型服务限流及宿主 incomplete_turn。控制器停止为 UNVERIFIED，没有自动重放可能已产生副作用的工具，也没有报告通过。
- 实际评审超时触发独立有限重试，未占用实际纠偏次数；后续评审恢复并完成闭环。
- 网页在任务尚未进入执行器前提交第二条消息，或只留在 Queued 而没有投递到活动运行时，可能成为下一回合。这不计作同一控制器接收成功；上表只计入有 ACKNOWLEDGED 记录的用例。
- 此版本 TUI 的 Ctrl+C 是退出提示；取消使用 Escape 或宿主原生 /stop。取消不会撤销取消前已经完成的工具操作。
- 开发阶段曾发现共享父 sandboxSessionKey 导致内部候选事件进入父界面；已改成独立事件身份并继承有效策略，再重跑上表文件闭环。修复前的测试不作为最终验收依据。
- 长评审曾因父任务缺少活动记录被宿主判为卡死；已补充真实原生进度同步。最终网页和终端闭环在临时配置的 90 秒无进展取消阈值下分别运行约 292 秒、184 秒，父运行收到 97、100 条实际进度，均通过。没有通过定时心跳掩盖无进展。
- 成功只表示原核心验收通过且已观察的本地证据在交付前仍匹配；外部服务的并发状态不属于本地文件指纹保证。
