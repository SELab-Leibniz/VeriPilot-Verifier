# 基线提取实验记录

日期：2026-10-28。起点：`b1297e0ac882d7f412412961d4a2ad08259f7c28`。本轮使用合成材料，未修改 MatrixAssistant。

## 协议与性能

首次本地测量：5 万行、125 条读取范围的缺口结果完全一致，原逐行算法约 112.44ms，区间算法约 0.28ms。240 个文件分三页完整检出，无重复。相同 240 文件无匹配查询首次约 204.82ms，重复页约 0.42ms。12 次串行刷新取得同一个会话身份，原协议每次新建。

大来源目录的合成启动提示移除重复身份清单后，从约 52.8KB 降至约 4.7KB。该结果只涉及启动元数据；完整原始请求、基线和来源仍必须读取。它不代表整体输入 token 减少同样比例。时间为单机单轮观察，重复运行以原始 JSON 为准。

## 真实模型语义试验

使用现有 Claude Code 可执行文件及其默认配置；返回的模型名为 `glm-5.3-flash`，不是指定 Anthropic 模型。无工具或业务材料。每个版本/样例各一次，共 7 次调用，不能估计稳定均值。

花店样例含 8 段用户要求。原提示输出 27 条；初版 skill 输出 19 条；补充操作分组示例后输出 8 组；最终缩短 skill 后输出 16 条。逐条对照保留必填/选填、库存拒绝不扣减、取消释放、手机号禁出、断网、本地存储、旧要求保留、隔离/排队/空闲、旧笔记非证据、取消清标识。最终分组仍有波动，不能声称固定为 8 条。

另一份在调优前未使用的 9 段跨段样例，原提示输出 22 条；中间版输出 7 组；最终短版输出 11 条。完整保留导入原子拒绝、失败日志行号/原因、成本禁出、查看/编辑权限、存在订单禁止停用、15 分钟替代 5 分钟且保留其他约束、恢复后四项检查与示例引文非授权。短版会把导入校验与失败日志分开，仍可定位到具体子条件。

**token 口径纠正：** CLI 顶层 `usage` 与累计 `modelUsage` 不同，不能把前者当成整个探针总量。例如中间版花店顶层 usage 合计为 1834，原提示为 1909；但累计 modelUsage 分别为 3315 与 3215，并没有整体节省。详细输出同时保留两种字段。

按 CLI 累计 `modelUsage` 的输入+输出统计：花店原提示 3215，初版 3843，中间版 3315，最终短版 4907；跨段样例原提示 2908，中间版 3957，最终短版 3446。对应原提示/最终短版墙钟时间：花店 27.681/40.318 秒，跨段样例 37.484/32.177 秒。因此真实模型的整体 token 节省和稳定提速**尚未证实**；结构化输出调用、skill 固定开销和随机生成会影响结果。`modelUsage.costBasis` 为 unknown，不将这些字段当成最终账单。

本轮可确认的是工具/协议性能、完整导航和更适中的语义分组。大来源目录消除重复启动元数据是确定的输入字节收益；小来源任务的 skill 开销仍需进一步测量。分组减少后反馈仍须指明失败子条件，不能把局部通过扩展成全部通过。

协议测试覆盖真实持久化回执边界、compact 检查点、来源权限、取消、版本围栏、候选批次与事务；语义样例不能替代这些校验。

## 回归与构建

完整回归以并发 2、单文件 180 秒运行 144 个测试文件：1706 项，1683 通过、21 跳过、2 失败。一个失败是 Windows 瞬态文件锁导致历史索引替换失败，已为持久化历史/候选增加最多三次短暂重试，候选每次重试仍检查原截止，历史写入重试也有界且不延长截止；新增故障注入证明可以恢复。另一项是反馈时序用例在组合运行时超过轮询窗口，未放宽其断言。

修复后对基线、审查引擎和原生任务传输复测 97 项全部通过，包含真实 MA Hook Runner；宿主集成文件独立重跑 28 项全部通过。不能把组合运行的两个失败隐去，也不声称后来重新执行了一次全量零失败。项目专用工具、分页、笔记过期和闲置释放测试另有通过记录。私有 skill 验证、OpenClaw 插件构建和打包后基线引擎导入检查通过。

全量首轮曾与实现文件调整重叠，并出现资源缺失和时间敏感失败；以本节固定实现后的完整回归与复测记录为准。

## 证据边界

本轮性能实验与少量语义探针支持工具效率及粒度调整的可行性；未测得长期 MA 模型循环、宿主 prompt-cache 命中率或 Electron 实际显示尺寸。复用身份不等于复用一个进程，也不等于跨宿主重启恢复。持续会话的历史输入增长由宿主 compact 管理，仍需长样本观测。

重跑方式见 [方案](baseline-extraction-optimization.md)。去敏的语义输出、两种用量字段与协议性能原始观察已保存至 `test/fixtures/baseline-experiment-observations.json`，包含失败的中间版本，未筛除不利结果。CLI 完整本地输出在 `.runtime-correction/baseline-experiment/`；该目录被 Git 忽略。前期探针未额外保存 systemPrompt，最终短版保存了实际提示，重跑脚本保留原提示对照。
