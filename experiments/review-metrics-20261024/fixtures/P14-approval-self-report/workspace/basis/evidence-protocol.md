Evidence protocol for this isolated prompt experiment:
All process captures in this fixture are controlled synthetic test data, not claims that a real business run was performed. Each tool result is bound by tool_use_id to its original arguments. complete:false means history is unavailable/incomplete, so absence cannot prove a violation. An assistant narrative or a derived summary is not an execution witness. The current source-state manifest is a program-supplied identity snapshot, not a test result.
